# 카드뉴스 디자인 가이드라인

> 신한라이프 브랜드 기반 — 인스타그램, 블로그, 카카오톡 등 카드뉴스 콘텐츠

---

## 1. 기본 사양

### 1.1 규격

| 포맷 | 크기 (px) | 비율 | 채널 |
|------|----------|------|------|
| 정사각형 | 1080 × 1080 | 1:1 | 인스타그램, 페이스북 |
| 세로형 | 1080 × 1350 | 4:5 | 인스타그램 피드 |
| 와이드형 | 1200 × 630 | 1.91:1 | 블로그, 카카오톡 |

### 1.2 장 수
- **최소 3장, 최대 10장** (인스타그램 캐러셀 기준)
- 권장: **5~7장** (집중도 유지)

### 1.3 파일
- 포맷: PNG (권장), JPG
- 해상도: 72dpi 이상
- 파일 크기: 장당 2MB 이하

## 2. 카드 구성 (Flow)

### 2.1 기본 흐름

```
[1] 커버       → 시선을 끄는 메인 타이틀
[2] 문제 제기   → 공감, 질문, 상황 설정
[3] 본문 1     → 핵심 정보 / 솔루션 1
[4] 본문 2     → 핵심 정보 / 솔루션 2
[5] 본문 3     → 핵심 정보 / 솔루션 3
[6] 요약/정리   → 핵심 메시지 정리
[7] CTA/마무리  → 행동 유도 + 로고
```

### 2.2 카드별 역할

#### 1장 — 커버
```
┌──────────────────────┐
│  [카테고리 태그]       │
│                      │
│   메인 타이틀         │
│   (2줄 이내)          │
│                      │
│   서브 카피           │
│                      │
│  [비주얼 요소]        │
│  [로고]               │
└──────────────────────┘
```
- 가장 중요한 카드 — 스크롤을 유도하는 후킹 타이틀
- 메인 타이틀: 크고 굵게, 호기심 유발
- 배경: 브랜드 컬러 or 임팩트 있는 비주얼

#### 2~5장 — 본문
```
┌──────────────────────┐
│  [페이지 번호/진행바]  │
│                      │
│  소제목               │
│                      │
│  본문 텍스트          │
│  (3~5줄 이내)         │
│                      │
│  [아이콘/일러스트]     │
│                      │
│  핵심 키워드 강조      │
└──────────────────────┘
```
- 한 카드에 **하나의 메시지**만 전달
- 텍스트 최소화, 비주얼 최대화
- 핵심 숫자/키워드는 크게, 색상으로 강조

#### 마지막 장 — CTA
```
┌──────────────────────┐
│                      │
│   핵심 메시지 요약    │
│                      │
│   ┌──────────────┐   │
│   │  CTA 버튼     │   │
│   └──────────────┘   │
│                      │
│   연락처/링크 정보    │
│   [로고]              │
└──────────────────────┘
```

## 3. 레이아웃 패턴

### 3.1 Type A — 상단 텍스트 + 하단 비주얼
- 텍스트 영역 40% + 비주얼 영역 60%
- 정보 전달형 카드뉴스에 적합

### 3.2 Type B — 좌우 분할
- 좌측 텍스트 50% + 우측 비주얼 50%
- 비교/대조형 콘텐츠에 적합

### 3.3 Type C — 중앙 정렬
- 텍스트와 비주얼 모두 중앙 배치
- 감성적/브랜드 캠페인 콘텐츠에 적합

### 3.4 Type D — 풀 비주얼 + 텍스트 오버레이
- 배경 이미지 위에 그라데이션 오버레이
- 스토리텔링/감성 콘텐츠에 적합

## 4. 컬러 적용

### 4.1 카드뉴스 컬러 테마

#### Theme 1 — 브랜드 퍼플
| 요소 | 컬러 | HEX |
|------|------|-----|
| 배경 | Contemporary Purple | `#6B3FA0` |
| 텍스트 | 화이트 | `#FFFFFF` |
| 강조 | 라이트 퍼플 | `#9B7AC7` |
| 악센트 | 골드 | `#FFD700` |

#### Theme 2 — 클린 화이트
| 요소 | 컬러 | HEX |
|------|------|-----|
| 배경 | 화이트 | `#FFFFFF` |
| 텍스트 | 다크 그레이 | `#1C1C1E` |
| 강조 | Contemporary Purple | `#6B3FA0` |
| 구분선 | 라이트 그레이 | `#E5E5EA` |

#### Theme 3 — 다크 모드
| 요소 | 컬러 | HEX |
|------|------|-----|
| 배경 | 다크 네이비 | `#1C1C2E` |
| 텍스트 | 화이트 | `#FFFFFF` |
| 강조 | 라이트 퍼플 | `#9B7AC7` |
| 악센트 | 스카이 블루 | `#4BAFF5` |

#### Theme 4 — 소프트 파스텔
| 요소 | 컬러 | HEX |
|------|------|-----|
| 배경 | 라벤더 | `#F0EBF8` |
| 텍스트 | 다크 퍼플 | `#4A2B73` |
| 강조 | Contemporary Purple | `#6B3FA0` |
| 악센트 | 코럴 핑크 | `#FF6B6B` |

### 4.2 규칙
- 하나의 카드뉴스 세트에서 **하나의 테마**만 사용
- 강조 색상은 한 카드당 **1~2곳**만 적용
- 페이지 간 컬러 톤 일관성 유지

## 5. 타이포그래피

### 5.1 텍스트 크기 (1080×1080 기준)

| 요소 | 크기 | 굵기 | 최대 글자수 |
|------|------|------|-----------|
| 커버 타이틀 | 56~72px | ExtraBold | 15자 |
| 소제목 | 36~44px | Bold | 20자 |
| 본문 | 24~28px | Regular | 줄당 15자 |
| 강조 숫자 | 72~96px | ExtraBold | 5자 |
| 캡션/출처 | 16~18px | Regular | 30자 |
| CTA | 28~32px | SemiBold | 10자 |

### 5.2 텍스트 규칙
- **한 카드당 텍스트 최대 5줄**
- 핵심 키워드는 **볼드 + 브랜드 컬러**로 강조
- 줄간격: 본문 1.6배, 타이틀 1.2배
- 장문 지양 — 한 문장에 하나의 메시지

## 6. 비주얼 요소

### 6.1 아이콘
- 라인 아이콘 (두께 2px), 사이즈 48~64px
- 브랜드 컬러 또는 화이트 사용
- 한 카드에 아이콘 1~3개

### 6.2 일러스트
- 플랫 스타일, 미니멀
- 인물 일러스트: 다양한 성별/연령 표현
- 브랜드 컬러 팔레트 내 색상 사용

### 6.3 사진
- 고해상도 라이프스타일 사진
- 텍스트 가독성을 위한 블러 or 오버레이 처리
- 밝은 톤, 자연스러운 색감

### 6.4 차트/그래프
- 심플한 바 차트, 파이 차트, 라인 그래프
- 데이터 시각화 시 브랜드 컬러 활용
- 수치는 크게, 레이블은 간결하게

### 6.5 구분 요소
- 페이지 번호: 우측 상단, 작은 원 인디케이터
- 진행 바: 상단에 얇은 프로그레스 바
- 구분선: 1px, `#E5E5EA` 또는 `rgba(255,255,255,0.2)`

## 7. 콘텐츠 유형별 가이드

### 7.1 상품 설명형
- 테마: 클린 화이트 or 소프트 파스텔
- 구성: 커버 → 상품 특징 3~4장 → 가입 방법 → CTA
- 핵심 혜택을 숫자/아이콘으로 시각화

### 7.2 정보/팁 제공형
- 테마: 클린 화이트 or 다크 모드
- 구성: 커버(질문형) → 팁 3~5개 → 요약 → CTA
- 넘버링(01, 02, 03...) 활용

### 7.3 이벤트/프로모션형
- 테마: 브랜드 퍼플 or 그라데이션
- 구성: 커버(이벤트명) → 혜택 → 참여 방법 → 기간/주의사항
- 임팩트 있는 숫자, 비비드한 악센트 컬러

### 7.4 브랜드 스토리형
- 테마: 풀 비주얼 + 오버레이
- 구성: 감성 카피 중심, 미니멀 텍스트
- 사진/일러스트 비중 높음

---

## 8. 금지 사항

- 카드당 텍스트 6줄 이상 금지
- 2가지 이상 폰트 혼용 금지
- 과도한 장식 요소(별, 반짝이, 네온) 금지
- 저해상도 이미지 사용 금지
- 일관성 없는 컬러 테마 혼용 금지
- 출처 없는 통계 데이터 사용 금지
- 로고 누락 금지 (커버 + 마지막 장 필수)
