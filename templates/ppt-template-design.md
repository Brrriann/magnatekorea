# PPT 템플릿 디자인 가이드라인

> 신한라이프 브랜드 기반 — 프레젠테이션 자료 디자인 시스템

---

## 1. 기본 사양

### 1.1 규격

| 항목 | 값 |
|------|-----|
| 크기 | 16:9 (33.867cm × 19.05cm) |
| 해상도 | 1920 × 1080px |
| 여백 | 상하좌우 최소 40px |
| 안전 영역 | 상하좌우 60px 내부 |
| 파일 포맷 | PPTX, PDF (공유용) |

### 1.2 마스터 슬라이드 구성

| 슬라이드 유형 | 용도 | 필수 |
|-------------|------|------|
| 표지 (Title) | 프레젠테이션 시작 | O |
| 목차 (TOC) | 전체 구조 안내 | O |
| 섹션 구분 (Divider) | 챕터 전환 | O |
| 콘텐츠 — 텍스트 | 텍스트 중심 설명 | O |
| 콘텐츠 — 이미지+텍스트 | 비주얼 + 설명 | O |
| 콘텐츠 — 2단 분할 | 좌우 비교/병렬 | O |
| 콘텐츠 — 차트/그래프 | 데이터 시각화 | O |
| 콘텐츠 — 타임라인 | 연혁/프로세스 | △ |
| 콘텐츠 — 팀/인물 | 조직 소개 | △ |
| 마무리 (Closing) | 감사, 연락처, Q&A | O |

- 핵심 키워드: Bold + 퍼플 컬러

## 5. 비주얼 요소

### 5.1 이미지
- 고해상도 (최소 1920px 너비)
- 라운드 코너: 12~16px
- 그림자: `0 4px 16px rgba(0,0,0,0.1)` (선택)
- 마스크: 원형, 라운드 사각형 등 활용

### 5.2 아이콘
- 라인 아이콘 (두께 2px)
- 크기: 32~48px
- 브랜드 컬러 또는 그레이스케일
- 아이콘 배경: 원형 `#F0EBF8` (선택)

### 5.3 도형
- 라운드 사각형: border-radius 12px
- 원: 아이콘 배경, 불릿 포인트
- 선: 1~2px, 구분선/연결선

### 5.4 패스파인더 활용
- 표지, 섹션 구분, 마무리 슬라이드에 장식으로 활용
- 투명도 10~15%
- 배경 우측 하단 배치

## 6. 레이아웃 규칙

### 6.1 정렬
- 좌측 정렬 기본 (타이틀, 본문)
- 중앙 정렬: 표지, 섹션 구분, 마무리
- 우측 정렬: 페이지 번호, 날짜

### 6.2 그리드
- 12컬럼 그리드 (1920px 기준)
- 거터: 24px
- 좌우 마진: 80px
- 상하 마진: 60px (헤더/푸터 영역 제외)

### 6.3 헤더 바
```

- 하단 구분선: 1px `#E5E5EA`

```

└─────────────────────────────────────────────────┘

- 높이: 32px
- 페이지 번호: 우측 하단, 10pt, `#8E8E93`

## 7. 차트 & 데이터 시각화

### 7.1 차트 유형별 가이드

#### 바 차트
- 바 너비: 40~60px
- 바 간격: 바 너비의 50%
- 라운드 코너: 상단 4px
- 데이터 레이블: 바 상단, 12pt, Bold

#### 라인 차트
- 선 두께: 3px
- 데이터 포인트: 원형, 8px
- 그리드라인: 1px, `#E5E5EA`, 점선
- 영역 채우기: 투명도 10%

#### 파이/도넛 차트
- 도넛 두께: 40px
- 중앙 텍스트: 총합 또는 핵심 수치
- 레이블: 외부 또는 범례

#### 표 (Table)
- 헤더 행: `#6B3FA0` 배경, `#FFFFFF` 텍스트
- 짝수 행: `#F5F5F7` 배경
- 홀수 행: `#FFFFFF` 배경
- 구분선: 1px `#E5E5EA`
- 셀 패딩: 12px

### 7.2 데이터 시각화 원칙
- 한 슬라이드에 차트 1~2개만
- 핵심 수치는 크게 강조 (32pt+, Bold, 퍼플)
- 단위와 출처 반드시 표기
- 불필요한 장식 요소 제거 (3D 효과, 그림자 등)
- 색상으로 의미 전달 (증가=그린, 감소=레드)

## 8. 애니메이션 (선택)

### 8.1 권장 애니메이션
| 유형 | 효과 | 시간 |
|------|------|------|
| 슬라이드 전환 | Fade 또는 Push | 0.5s |
| 요소 등장 | Fade + Rise Up | 0.3s |
| 차트 데이터 | Wipe (좌→우) | 0.5s |
| 불릿 포인트 | 순차 Fade In | 0.2s 간격 |

### 8.2 금지 애니메이션
- 회전, 바운스, 스윙 등 과도한 효과
- 3D 전환 효과
- 사운드 효과
- 자동 재생 타이밍 (수동 클릭 권장)

## 9. 금지 사항

- 슬라이드당 텍스트 8줄 이상 금지
- 2가지 이상 서체 혼용 금지
- 브랜드 컬러 팔레트 외 색상 남용 금지
- 저해상도 이미지 사용 금지
- 워드아트, 클립아트 사용 금지
- 과도한 애니메이션/전환 효과 금지
- 슬라이드 번호 누락 금지 (표지 제외)
- 출처 없는 데이터/통계 금지
- 로고 없는 표지/마무리 슬라이드 금지
