# 썸네일 디자인 가이드라인

> 신한라이프 브랜드 기반 — SNS, 블로그, 유튜브 등 디지털 채널용 썸네일

---

## 1. 기본 사양

### 1.1 사이즈 규격

| 채널 | 크기 (px) | 비율 | 용도 |
|------|----------|------|------|
| 유튜브 썸네일 | 1280 × 720 | 16:9 | 영상 미리보기 |
| 인스타그램 피드 | 1080 × 1080 | 1:1 | 정사각형 포스트 |
| 인스타그램 릴스 | 1080 × 1920 | 9:16 | 세로형 콘텐츠 |
| 블로그 대표이미지 | 1200 × 630 | 1.91:1 | 네이버/티스토리 |
| 페이스북 공유 | 1200 × 630 | 1.91:1 | 링크 미리보기 |
| 카카오톡 공유 | 800 × 400 | 2:1 | 메시지 미리보기 |

### 1.2 해상도
- 최소 72dpi (웹), 권장 150dpi
- 파일 포맷: PNG (투명 배경 필요 시), JPG (사진 중심)
- 파일 크기: 2MB 이하 권장

## 2. 레이아웃 구조

### 2.1 기본 구성 요소
```
┌─────────────────────────────────────┐
│  [카테고리 태그]                      │
│                                     │
│  메인 타이틀                         │
│  (최대 2줄)                          │
│                                     │
│  서브 텍스트 (선택)                   │
│                                     │
│           [비주얼 요소/사진]          │
│                                     │
│  [로고]              [CTA/아이콘]    │
└─────────────────────────────────────┘
```

### 2.2 레이아웃 유형

#### Type A — 좌측 텍스트 + 우측 비주얼 (가장 기본)
```
┌──────────────────────────────────┐
│ [태그]                            │
│                                  │
│ 메인 타이틀        ┌──────────┐  │
│ 최대 2줄           │  이미지   │  │
│                    │  /일러스트 │  │
│ 서브텍스트         └──────────┘  │
│                                  │
│ [로고]                           │
└──────────────────────────────────┘
```

#### Type B — 중앙 정렬 (브랜드/이벤트용)
```
┌──────────────────────────────────┐
│           [태그]                  │
│                                  │
│        메인 타이틀                │
│        (중앙 정렬)               │
│                                  │
│        서브텍스트                 │
│                                  │
│         [CTA]                    │
│ [로고]                           │
└──────────────────────────────────┘
```

#### Type C — 풀 비주얼 + 오버레이 (감성/라이프스타일용)
```
┌──────────────────────────────────┐
│ ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░ │
│ ░░░░ 배경 이미지 풀 ░░░░░░░░░░░ │
│ ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░ │
│ ▓▓▓▓▓ 그라데이션 오버레이 ▓▓▓▓▓ │
│ ▓▓  메인 타이틀              ▓▓ │
│ ▓▓  서브텍스트    [로고]     ▓▓ │
└──────────────────────────────────┘
```

## 3. 컬러 적용

### 3.1 배경 컬러 조합

| 유형 | 배경 | 텍스트 | 악센트 |
|------|------|--------|--------|

| **다크 퍼플** | `#4A2B73` | `#FFFFFF` | `#9B7AC7` |

## 4. 타이포그래피

### 4.1 텍스트 크기 (1280×720 기준)

| 요소 | 크기 | 굵기 | 행간 |
|------|------|------|------|
| 카테고리 태그 | 20~24px | SemiBold | 1.0 |
| 메인 타이틀 | 48~64px | ExtraBold | 1.2 |
| 서브 텍스트 | 24~28px | Medium | 1.3 |
| CTA 텍스트 | 20~24px | Bold | 1.0 |

### 4.2 텍스트 규칙
- 메인 타이틀: **최대 2줄, 15자 이내** (한 줄 권장)
- 서브 텍스트: **최대 1줄, 20자 이내**
- 자간: -2% ~ 0%
- 텍스트에 그림자 또는 아웃라인 사용 시 과하지 않게 적용
- 핵심 키워드에 **색상 강조** (Contemporary Purple 또는 보색)

## 5. 비주얼 요소

### 5.1 사진 사용
- 밝고 선명한 라이프스타일 사진
- 따뜻한 톤 보정 (웜 필터)
- 인물 사진: 자연스러운 표정, 긍정적인 감정
- 배경 블러 처리하여 텍스트 가독성 확보

### 5.2 일러스트 / 아이콘
- 플랫 스타일, 라인 아이콘
- 브랜드 컬러 팔레트 내 색상 사용
- 복잡하지 않은 심플한 형태

### 5.3 패스파인더 모티프
- 상승 곡선 그래픽을 배경 장식으로 활용
- 투명도 10~20%로 은은하게 적용
- 그라데이션 적용 가능

### 5.4 로고 배치
- 좌측 하단 또는 우측 하단
- 배경 대비 가독성 확보
- 최소 크기: 가로 80px

## 6. 스타일별 예시 가이드

### 6.1 상품 소개형
- 배경: 라이트 그레이 or 화이트
- 좌측: 상품명 + 핵심 혜택 텍스트
- 우측: 관련 일러스트 or 아이콘
- 하단: 로고 + "자세히 보기" CTA

### 6.2 이벤트/프로모션형
- 배경: 퍼플 그라데이션 or 비비드 컬러
- 중앙: 이벤트명 대형 타이틀
- 할인율/혜택 숫자 강조 (큰 폰트 + 골드 컬러)
- 긴급감 표현: "D-7", "한정" 등 배지

### 6.3 정보/교육형
- 배경: 화이트 or 라이트
- 좌측 상단: 카테고리 태그
- 중앙: 질문형 or 숫자형 타이틀 ("알고 계셨나요?", "5가지 방법")
- 하단: 로고

### 6.4 브랜드 캠페인형
- 배경: 풀 이미지 + 다크 그라데이션 오버레이
- 감성적 카피 (큰 타이틀)
- 최소한의 텍스트
- 로고 돋보이게 배치

## 7. 금지 사항

- 브랜드 컬러 팔레트 외 색상을 주요 색상으로 사용 금지
- 텍스트 3줄 이상 금지
- 저해상도/흐릿한 이미지 사용 금지
- 과도한 그림자, 3D 효과, 네온 효과 금지
- 로고 위에 텍스트 겹침 금지
- 경쟁사 비교 / 비하 콘텐츠 금지
