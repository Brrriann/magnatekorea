# 뉴스레터 디자인 가이드라인

> 신한라이프 브랜드 기반 — 이메일 뉴스레터 디자인 시스템

---

## 1. 기본 사양

### 1.1 규격

| 항목 | 값 |
|------|-----|
| 전체 너비 | 600px (이메일 표준) |
| 콘텐츠 너비 | 560px (좌우 패딩 20px) |
| 최대 높이 | 제한 없음 (스크롤) |
| 배경색 | `#F5F5F7` (외부), `#FFFFFF` (콘텐츠) |
| 포맷 | HTML 이메일 (인라인 CSS) |

### 1.2 호환성
- Gmail, Outlook, Apple Mail, Naver Mail, Daum Mail 호환
- 반응형: 모바일 320px ~ 데스크톱 600px
- 이미지 alt 텍스트 필수 (이미지 차단 환경 대응)
- 웹폰트 미지원 환경 대비 시스템 폰트 fallback

## 11. 반응형 처리

### 11.1 모바일 대응 (< 480px)
- 2단 그리드 → 1단 스택
- 이미지 너비 100%
- 폰트 크기 유지 (최소 14px)
- CTA 버튼 전체 너비
- 좌우 패딩 16px

### 11.2 미디어 쿼리
```css
@media only screen and (max-width: 480px) {
  .container { width: 100% !important; }
  .column { display: block !important; width: 100% !important; }
  .button { width: 100% !important; text-align: center !important; }
}
```

## 12. 금지 사항

- JavaScript 사용 금지 (이메일 클라이언트 미지원)
- 외부 CSS 파일 링크 금지 (인라인 CSS만 사용)
- 배경 이미지 의존 금지 (Outlook 미지원)
- 웹폰트 단독 의존 금지 (fallback 필수)
- 전체 이미지로만 구성된 뉴스레터 금지
- 수신거부 링크 누락 금지 (법적 필수)
- 이미지 alt 텍스트 누락 금지
