## 3. 주요 사업 영역

### 3.1 보험 상품 라인업

| 카테고리 | 상품 유형 | 타겟 |
|---------|----------|------|
| **종신/정기보험** | 사망보장, 가족 보호 | 가장, 부양가족 보유 고객 |
| **연금/저축보험** | 노후 대비, 자산 축적 | 은퇴 준비 세대 |

| **건강보험** | 질병/상해 보장 | 전 연령대 |
| **간편가입보험** | 유병자/고령자 대상 | 기존 보험 가입 어려운 고객 |
| **디지털보험** | 온라인 전용, 합리적 보험료 | MZ세대, 디지털 친화 고객 |

### 3.2 디지털 서비스

| 서비스 | 설명 |
|--------|------|
| **신한 SOL라이프** | 보험 가입, 조회, 변경, 청구를 원스톱으로 처리하는 대표 앱 |
| **디지털보험** | 라이프스타일 맞춤 설계부터 가입 완료까지 온라인 처리 |
| **S-패스 (Smart Claims Pass)** | AI 기반 보험금 신속 지급 서비스, 실시간 데이터 분석 |
| **생성형 AI 활용** | 2만종 보험 서류 디지털 전환, 업무 효율화 |

## 4. 타겟 고객

### 4.1 주요 세그먼트

| 세그먼트 | 연령대 | 니즈 | 채널 선호 |
|---------|--------|------|-----------|
| **MZ세대** | 20~30대 | 합리적 보험, 디지털 경험 | 앱, 온라인 |
| **영 패밀리** | 30~40대 | 가족 보장, 자녀 교육 | 앱 + 대면 |
| **미들 에이지** | 40~50대 | 건강, 은퇴 준비 | 대면 + 앱 |
| **시니어** | 60대+ | 간편 가입, 건강 보장 | 대면, 콜센터 |

### 4.2 고객 특성
- 디지털 전환에 대한 수용도가 높은 고객 확대 중
- 비대면 채널 선호 고객 증가
- 보험 = 복잡하다는 인식 → 쉽고 직관적인 경험 요구
- 가성비 + 맞춤형 보장 동시 추구

## 7. 디지털 전환 전략

### 7.1 핵심 방향
```
고객 경험 혁신 ──→ 비대면 채널 고도화
       │
업무 효율화 ────→ AI/RPA 기반 자동화
       │
데이터 활용 ────→ 개인화 마케팅, 리스크 관리
       │
신사업 확대 ────→ 헬스케어, 플랫폼 비즈니스
```

### 7.2 기술 스택
- **AI/ML**: 보험금 심사 자동화, 사기 탐지
- **생성형 AI**: 서류 디지털 전환, 고객 응대
- **클라우드**: 인프라 현대화
- **데이터 분석**: 고객 행동 분석, 맞춤 상품 추천

## 8. 마케팅 & 브랜딩

### 8.1 브랜드 캠페인 특징
- **버추얼 인플루언서 "로지(ROZY)"** 활용 — MZ세대 타겟
- 캠페인 1000만뷰 3연속 달성
- 디지털 감성, 젊고 세련된 이미지 지향

### 8.2 주요 마케팅 채널
| 채널 | 목적 |
|------|------|
| TV/영상 광고 | 브랜드 인지도, 이미지 구축 |
| 디지털 광고 | 타겟팅, 전환 유도 |
| SNS | 브랜드 친밀도, 고객 소통 |
| 콘텐츠 마케팅 | 보험 정보 제공, 신뢰 구축 |
| 제휴 마케팅 | 그룹사 교차 판매 |

### 8.3 콘텐츠 방향성
- 보험을 어렵지 않게 — 쉬운 언어, 비주얼 중심
- 라이프스타일 연결 — 일상 속 보험의 가치
- 데이터 기반 스토리텔링 — 숫자와 사례 활용
- 디지털 네이티브 감성 — 숏폼, 인터랙티브 콘텐츠
